# 🎲 JavaScript Random Number Generator

A simple and interactive Random Number Generator built using **HTML, CSS, and JavaScript**.

This project generates random numbers through a clean and user-friendly interface. It is a beginner-friendly JavaScript project created to practice DOM manipulation, JavaScript functions, and event handling.

## ✨ Features

- Generate random numbers instantly.
- Simple and user-friendly interface.
- Responsive design.
- Built with vanilla JavaScript.
- Clean and lightweight design.
